PROJECT TITLE:
    IoT-Based Anti-Theft Floor Mat System with Gmail Email Alerts

DESCRIPTION:
    This project is an IoT-based home security system that uses:
    - Piezoelectric / voltage sensors embedded in a floor mat to detect footsteps
    - A servo motor that sweeps to point a camera toward the detected direction
    - A webcam with face recognition to identify known family members vs unknown intruders
    - Gmail email alerts sent automatically when someone is detected
    - A Flask web application for managing family members and viewing live detection
    - An Arduino board that communicates with the Flask server over serial (USB)

HOW THE SYSTEM WORKS:
    1. Voltage sensors (left and right) on a floor mat detect when someone steps on it
    2. Arduino reads which side was triggered (left or right)
    3. Arduino rotates the servo motor to aim the camera toward that side
    4. Arduino sends the trigger direction ("L" or "R") to the Flask server via serial
    5. Flask activates the webcam and performs face recognition
    6. If the face matches a registered family member → welcome email is sent
    7. If the face is unknown → security alert email is sent with the captured photo
    8. Arduino plays a buzzer melody (welcome) or alarm (unknown) accordingly

================================================================================
                        TECHNOLOGIES USED
================================================================================

Hardware:
    - Arduino Uno
    - Piezoelectric / Voltage sensors (left: A0, right: A1)
    - Servo Motor (pin D5)
    - Buzzer (pin D6)
    - IR Sensor (pin D7) for system restart
    - USB webcam

Software:
    - Python 3.10 / 3.11 / 3.12
    - Flask (web framework)
    - OpenCV (camera + image processing)
    - face_recognition (face detection + matching using dlib)
    - yagmail (Gmail email sending)
    - pyserial (Arduino serial communication)
    - Arduino IDE (for uploading Arduino code)
    - Proteus (circuit simulation)
